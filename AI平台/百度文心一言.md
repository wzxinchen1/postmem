# 百度文心一言 API 协议

## 1. 基础请求格式

```http
POST /rpc/2.0/ai_custom/v1/wenxinworkshop/chat/completions?access_token=xxx HTTP/1.1
Host: aip.baidubce.com
Content-Type: application/json

{
  "model": "ernie-4.0-8k",
  "messages": [
    {"role": "user", "content": "解释自然语言处理的发展历程"}
  ],
  "stream": true
}
```

## 2. 获取 Access Token

```http
POST /oauth/2.0/token?grant_type=client_credentials&client_id=xxx&client_secret=xxx HTTP/1.1
Host: aip.baidubce.com
```

响应：
```json
{
  "access_token": "xxx",
  "expires_in": 2592000
}
```

## 3. 流式响应报文示例

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

// 数据块格式
data: {"id":"xxx","object":"chat.completion","created":1234567890,"result":"自","is_truncated":false,"need_clear_history":false,"finish_reason":null,"usage":{"prompt_tokens":10,"completion_tokens":1,"total_tokens":11}}

data: {"id":"xxx","object":"chat.completion","created":1234567890,"result":"然","is_truncated":false,"need_clear_history":false,"finish_reason":null,"usage":{"prompt_tokens":10,"completion_tokens":2,"total_tokens":12}}

// ... 更多内容

data: {"id":"xxx","object":"chat.completion","created":1234567890,"result":"","is_truncated":false,"need_clear_history":false,"finish_reason":"stop","usage":{"prompt_tokens":10,"completion_tokens":100,"total_tokens":110}}
```

**字段说明**:
- `result`: 增量文本内容
- `is_truncated`: 是否被截断
- `need_clear_history`: 是否需要清空历史
