# 腾讯混元 API 协议

## 1. 基础请求格式

```http
POST /api/v3/chat/completions HTTP/1.1
Host: api.hunyuan.cloud.tencent.com
Authorization: Bearer xxx
Content-Type: application/json

{
  "model": "hunyuan-lite",
  "messages": [
    {"role": "user", "content": "解释区块链的工作原理"}
  ],
  "stream": true
}
```

## 2. 流式响应报文示例

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

// 兼容 OpenAI 格式
data: {"id":"xxx","choices":[{"delta":{"content":"区"},"finish_reason":null,"index":0}],"created":1234567890,"model":"hunyuan-lite","object":"chat.completion.chunk"}

data: {"id":"xxx","choices":[{"delta":{"content":"块"},"finish_reason":null,"index":0}],"created":1234567890,"model":"hunyuan-lite","object":"chat.completion.chunk"}

// ... 更多内容

data: {"id":"xxx","choices":[{"delta":{},"finish_reason":"stop","index":0}],"created":1234567890,"model":"hunyuan-lite","object":"chat.completion.chunk","usage":{"prompt_tokens":10,"completion_tokens":100,"total_tokens":110}}

data: [DONE]
```
