# 腾讯混元 API 协议

## 1. 基础请求格式

### 1.1 接口信息

- **接口请求域名**：`hunyuan.tencentcloudapi.com`
- **接口名称**：ChatCompletions（对话补全）
- **协议支持**：支持流式（SSE协议）和非流式两种调用方式
- **并发限制**：默认单账号限制并发数为 5 路，如需提高需购买

### 1.2 基础请求示例

```http
POST / HTTP/1.1
Host: hunyuan.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ChatCompletions
X-TC-Version: 2023-09-01
Authorization: Bearer xxx

{
  "Model": "hunyuan-turbo",
  "Messages": [
    {"Role": "user", "Content": "解释量子计算的基本原理"}
  ],
  "Stream": true
}
```

## 2. 输入参数详解

### 2.1 公共参数

| 参数名称 | 必选 | 类型 | 描述 |
|---------|------|------|------|
| Action | 是 | String | 固定值：`ChatCompletions` |
| Version | 是 | String | 固定值：`2023-09-01` |
| Region | 否 | String | 可选参数 |

### 2.2 业务参数

| 参数名称 | 必选 | 类型 | 描述 |
|---------|------|------|------|
| **Model** | 是 | String | 模型名称 |
| **Messages.N** | 是 | Array of Message | 聊天上下文信息，最多40条 |
| Stream | 否 | Boolean | 流式调用开关，默认 false |
| StreamModeration | 否 | Boolean | 流式输出审核开关，默认 true |
| TopP | 否 | Float | 影响输出多样性，取值 [0.0, 1.0]，默认 1.0 |
| Temperature | 否 | Float | 影响输出随机性，取值 [0.0, 2.0]，默认 0.6 |
| EnableEnhancement | 否 | Boolean | 功能增强（如搜索）开关，默认关闭 |
| Tools.N | 否 | Array of Tool | 可调用的工具列表 |
| ToolChoice | 否 | String | 工具使用选项：`none`、`auto`、`custom` |
| CustomTool | 否 | Tool | 强制调用的指定工具 |
| SearchInfo | 否 | Boolean | 是否返回搜索信息，默认 false |
| Citation | 否 | Boolean | 搜索引文角标开关，默认 false |
| EnableSpeedSearch | 否 | Boolean | 极速版搜索开关，默认 false |
| Seed | 否 | Integer | 确保输出可复现，取值 1-10000 |
| Stop.N | 否 | Array of String | 自定义结束生成字符串 |
| EnableThinking | 否 | Boolean | 模型思维链开关（仅 hunyuan-a13b 生效） |

### 2.3 Messages 结构说明

**Role 可选值**：
- `system`：系统消息（可选，必须位于最开始）
- `user`：用户消息
- `assistant`：助手消息
- `tool`：工具消息

**顺序规则**：
- `system` 可选，必须位于最开始
- `user` 和 `assistant` 需交替出现
- 以 `user` 提问开始，`user` 或 `tool` 提问结束
- 示例：`[system(可选), user, assistant, user(tool, tool...), assistant, user(tool, tool...), ...]`

### 2.4 可用模型列表

| 模型名称 | 说明 |
|---------|------|
| hunyuan-turbo | 标准版模型 |
| hunyuan-turbos-latest | 最新标准版 |
| hunyuan-functioncall | 支持函数调用 |
| hunyuan-vision | 支持图像理解 |
| hunyuan-turbos-vision-video | 支持视频理解 |
| hunyuan-a13b | 支持思维链 |

## 3. 开启思考链（EnableThinking）

腾讯混元的 hunyuan-a13b 模型支持思考链功能：

```http
POST / HTTP/1.1
Host: hunyuan.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ChatCompletions

{
  "Model": "hunyuan-a13b",
  "Messages": [
    {"Role": "user", "Content": "请分析：为什么天空是蓝色的？"}
  ],
  "EnableThinking": true,
  "Stream": true
}
```

**关键说明**：
- 仅 `hunyuan-a13b` 模型支持思考链功能
- 默认开启思考链
- 思考过程会在生成最终回答前进行内部推理

## 4. 流式响应报文示例

### 4.1 流式请求

```http
POST / HTTP/1.1
Host: hunyuan.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ChatCompletions

{
  "Model": "hunyuan-turbo",
  "Stream": true,
  "Messages": [
    {"Role": "user", "Content": "计算1+1"}
  ]
}
```

### 4.2 流式响应（SSE 格式）

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Transfer-Encoding: chunked

data: {"Note":"以上内容为AI生成...","Choices":[{"FinishReason":"","Delta":{"Role":"assistant","Content":"1"}}],"Created":1700549760,"Id":"148b89ef-14e1-489f-8e70-b767e5b27d56","Usage":{"PromptTokens":4,"CompletionTokens":2,"TotalTokens":6}}

data: {"Note":"以上内容为AI生成...","Choices":[{"FinishReason":"","Delta":{"Role":"assistant","Content":"+"}}],...}

data: {"Note":"以上内容为AI生成...","Choices":[{"FinishReason":"","Delta":{"Role":"assistant","Content":"1"}}],...}

data: {"Note":"以上内容为AI生成...","Choices":[{"FinishReason":"","Delta":{"Role":"assistant","Content":"="}}],...}

data: {"Note":"以上内容为AI生成...","Choices":[{"FinishReason":"","Delta":{"Role":"assistant","Content":"2"}}],...}

data: {"Note":"以上内容为AI生成...","Choices":[{"FinishReason":"stop","Delta":{"Role":"assistant","Content":""}}],...}
```

**字段说明**：
- `Delta.Role`: 仅在第一个块中出现，标识角色为 assistant
- `Delta.Content`: 增量文本内容，需要拼接
- `FinishReason`: 结束原因
  - `stop`: 正常结束
  - `length`: 达到 token 限制
  - `tool_calls`: 需要调用工具
  - `null`: 未结束
- `Note`: 免责声明

## 6. Function Calling（工具调用）

### 6.1 工具调用请求

```http
POST / HTTP/1.1
Host: hunyuan.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ChatCompletions

{
  "Model": "hunyuan-functioncall",
  "Messages": [
    {"Role": "user", "Content": "北京和深圳今天天气如何"}
  ],
  "Tools": [
    {
      "Type": "function",
      "Function": {
        "Name": "get_current_weather",
        "Description": "获取当前地点的天气",
        "Parameters": "{\"type\":\"object\",\"properties\":{\"location\":{\"type\":\"string\",\"description\":\"城市名称\"},\"unit\":{\"type\":\"string\",\"enum\":[\"celsius\",\"fahrenheit\"]}},\"required\":[\"location\"]}"
      }
    }
  ],
  "ToolChoice": "auto"
}
```

### 6.2 工具调用响应

```json
{
  "Choices": [
    {
      "Message": {
        "Role": "assistant",
        "Content": "使用get_current_weather工具来获取北京和深圳的当前天气情况。",
        "ToolCalls": [
          {
            "Type": "function",
            "Function": {
              "Name": "get_current_weather",
              "Arguments": "{\"location\":[\"北京\",\"深圳\"],\"unit\":\"celsius\"}"
            }
          }
        ]
      },
      "FinishReason": "tool_calls"
    }
  ]
}
```

## 8. 输出参数详解

### 8.1 响应字段

| 参数名称 | 类型 | 描述 |
|---------|------|------|
| Created | Integer | Unix 时间戳（秒） |
| Usage | Usage | Token 统计信息 |
| Note | String | 免责声明 |
| Id | String | 本次请求的 RequestId |
| Choices | Array of Choice | 回复内容 |
| ErrorMsg | ErrorMsg | 错误信息（流式返回异常时） |
| SearchInfo | SearchInfo | 搜索结果信息 |
| RecommendedQuestions | Array of String | 推荐问答（最多3条） |
| RequestId | String | 唯一请求 ID |

### 8.2 Usage 结构

| 字段 | 描述 |
|------|------|
| PromptTokens | 输入 Token 数 |
| CompletionTokens | 输出 Token 数 |
| TotalTokens | 总 Token 数 |

| 错误码 | 描述 |
|--------|------|
| `FailedOperation.EngineRequestTimeout` | 引擎层请求超时；请稍后重试 |
| `FailedOperation.EngineServerError` | 引擎层内部错误；请稍后重试 |
| `FailedOperation.EngineServerLimitExceeded` | 引擎层请求超过限额；请稍后重试 |
| `FailedOperation.FreeResourcePackExhausted` | 免费资源包余量已用尽，请购买资源包或开通后付费 |
| `FailedOperation.ResourcePackExhausted` | 资源包余量已用尽，请购买资源包或开通后付费 |

## 10. 重要注意事项

1. **流式审核**：当 `StreamModeration=true` 时，可能出现部分内容已输出但审核未通过的情况，需自行撤回已上屏内容
2. **Token 计费**：按总 Token 数量计费
3. **OpenAI 兼容**：支持 OpenAI 兼容接口调用
4. **Stop 参数差异**：混元接口会停止在匹配到 stop 内容**之后**，而 OpenAI 是**之前**
5. **功能增强**：2025-04-20 起，`EnableEnhancement` 默认从开启改为关闭
6. **图片内容**：本接口暂不支持返回图片内容

## 12. 签名方法

腾讯云 API 使用签名方法 V3 进行身份验证，需要：
- **SecretId**：用于标识 API 调用者身份
- **SecretKey**：用于验证 API 调用者身份

签名计算四步骤：
```
步骤1: 拼接规范请求串
       ↓
步骤2: 拼接待签名字符串
       ↓
步骤3: 计算签名 (HMAC-SHA256)
       ↓
步骤4: 拼接 Authorization 头
```
