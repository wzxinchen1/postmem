# 讯飞星辰 API 协议

## 1. 基础请求格式

讯飞星辰提供两种API协议：**WebSocket协议**（原生星火大模型）和**HTTP协议**（MaaS平台，兼容OpenAI格式）。

### 1.1 WebSocket 协议（原生星火大模型）

```http
POST wss://spark-api.xf-yun.com/v4.0/chat
Authorization: 需要签名鉴权（见第2节）
Content-Type: application/json

{
  "header": {
    "app_id": "123456",
    "uid": "user123"
  },
  "parameter": {
    "chat": {
      "domain": "4.0Ultra",
      "temperature": 0.5,
      "max_tokens": 2048,
      "top_k": 4
    }
  },
  "payload": {
    "message": {
      "text": [
        {"role": "user", "content": "解释量子计算的基本原理"}
      ]
    }
  }
}
```

### 1.2 HTTP 协议（MaaS平台，兼容OpenAI）

```http
POST https://maas-api.cn-huabei-1.xf-yun.com/v2/chat/completions HTTP/1.1
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "model": "xdeepseekv3",
  "messages": [
    {"role": "user", "content": "解释量子计算的基本原理"}
  ],
  "stream": true,
  "temperature": 0.7,
  "max_tokens": 4096
}
```

## 2. 鉴权机制（WebSocket协议）

### 2.1 鉴权参数

在请求URL后添加以下参数：

| 参数 | 类型 | 必传 | 说明 |
|------|------|------|------|
| host | string | 是 | 请求主机，如：`spark-api.xf-yun.com` |
| date | string | 是 | 当前时间戳，RFC1123格式，如：`Fri, 17 Jul 2020 06:26:58 GMT` |
| authorization | string | 是 | 使用base64编码的签名相关信息 |

**重要提示**：
- `date` 必须是 UTC+0 或 GMT 时区，RFC1123 格式
- 服务端会对 date 进行时钟偏移检查，**最大允许 300 秒偏差**，超出将被拒绝

### 2.2 签名生成步骤

#### 步骤 1：获取密钥

在讯飞开放平台控制台创建应用后，获取：
- **AppID**：应用ID
- **APIKey**：32位字符串
- **APISecret**：32位字符串

#### 步骤 2：生成 signature_origin

拼接格式（`\n` 为换行符，`:` 后面有一个空格）：

```
host: $host
date: $date
$request-line
```

**示例**：
```
host: spark-api.xf-yun.com
date: Fri, 17 Jul 2020 06:26:58 GMT
GET /v4.0/chat HTTP/1.1
```

#### 步骤 3：使用 HMAC-SHA256 算法签名

```
signature_sha = hmac-sha256(signature_origin, $apiSecret)
```

#### 步骤 4：Base64 编码获得 signature

```
signature = base64(signature_sha)
```

#### 步骤 5：拼接 authorization_origin

```
api_key="$api_key", algorithm="hmac-sha256", headers="host date request-line", signature="$signature"
```

#### 步骤 6：Base64 编码获得最终 authorization

```
authorization = base64(authorization_origin)
```

### 2.3 完整请求 URL 示例

```
wss://spark-api.xf-yun.com/v4.0/chat?authorization=YXBpX2tleT0i...&host=spark-api.xf-yun.com&date=Fri%2C+17+Jul+2020+06%3A26%3A58+GMT
```

### 2.4 鉴权失败错误码

| HTTP Code | 说明 | 解决方法 |
|-----------|------|----------|
| 401 | 缺少 authorization 参数 | 检查是否有 authorization 参数 |
| 401 | 签名参数解析失败 | 检查签名参数是否完整，api_key 是否正确 |
| 401 | 签名校验失败 | 检查 api_key/api_secret 正确性，参数拼接格式 |
| 403 | 时钟偏移校验失败 | 检查服务器时间，相差5分钟以上会报错 |

### 3.3 请求参数说明

#### WebSocket 协议参数

**Header 参数**：

| 字段名 | 类型 | 必传 | 含义 | 限制 |
|--------|------|------|------|------|
| header.app_id | string | 是 | 应用的app_id | maxLength: 8 |
| header.uid | string | 否 | 用户id，用于后续扩展 | maxLength: 32 |

**Chat 参数**：

| 字段名 | 类型 | 必传 | 含义 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| parameter.chat.domain | string | 是 | 需要使用的领域 | - | 见模型列表 |
| parameter.chat.temperature | float | 否 | 核采样阈值 | 0.5 | 取值范围 (0, 1] |
| parameter.chat.top_k | int | 否 | 从k个中随机选择一个 | 4 | 最小值1，最大值6 |
| parameter.chat.max_tokens | int | 否 | 回答的tokens最大长度 | 2048 | 最小值1，最大值8192 |
| parameter.chat.auditing | string | 否 | 内容审核严格程度 | default | strict/moderate/show/default |
| parameter.chat.chat_id | string | 否 | 关联会话chat | - | 需保障用户下唯一 |
| parameter.chat.search_disable | boolean | 否 | 关闭云端搜索 | false | true为关闭 |
| parameter.chat.function_choice | string | 否 | function选择功能 | - | 缺省为模型自主判断 |

#### HTTP 协议参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| model | string | ✅ 是 | - | 要调用的模型ID |
| messages | array | ✅ 是 | - | 对话上下文消息列表 |
| stream | boolean | 否 | false | 是否采用流式响应模式 |
| temperature | float | 否 | 0.7 | 核采样阈值，取值[0,1] |
| max_tokens | int | 否 | 2048 | 限制生成回复的最大token数量 |
| reasoning_effort | string | 否 | high | 推理深度：low/medium/high，仅对OpenAI OSS模型生效 |
| stop | string[] | 否 | - | 停止词列表，最多4个字符串 |
| search_disable | boolean | 否 | true | 关闭联网搜索 |
| show_ref_label | boolean | 否 | false | 联网搜索时返回信源信息 |
| enable_thinking | boolean | 否 | false | 开启深度思考模式 |
| response_format | object | 否 | - | 指定输出格式，如 `{"type": "json_object"}` |
| tools | array | 否 | - | 工具列表，用于Function Calling |
| tool_choice | string | 否 | auto | 工具选择策略：auto/none/required |

### 3.4 Messages 参数格式

**单轮交互**：
```json
[
  {"role": "user", "content": "你会做什么？"}
]
```

**多轮交互**：
```json
[
  {"role": "system", "content": "你是星火认知大模型"},
  {"role": "user", "content": "你好"},
  {"role": "assistant", "content": "你好！"},
  {"role": "user", "content": "你是谁？"}
]
```

**多模态内容（HTTP协议）**：
```json
[{
  "role": "user",
  "content": [
    {"type": "text", "text": "请分析这张图片"},
    {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}}
  ]
}]
```

**字段说明**：

| 字段 | 含义 | 取值范围 |
|------|------|----------|
| role | 角色 | user, assistant, system, tool |
| content | 文本内容 | 字符串或数组格式 |

## 4. 流式响应报文示例

### 4.1 WebSocket 协议流式响应

```json
// 第一个数据块
{
  "header": {
    "code": 0,
    "message": "Success",
    "sid": "cht000704fa@dx16ade44e4d87a1c802",
    "status": 0
  },
  "payload": {
    "choices": {
      "status": 0,
      "seq": 0,
      "text": [
        {
          "content": "",
          "index": 0,
          "role": "assistant"
        }
      ]
    }
  }
}

// 中间数据块
{
  "header": {
    "code": 0,
    "message": "Success",
    "sid": "cht000704fa@dx16ade44e4d87a1c802",
    "status": 1
  },
  "payload": {
    "choices": {
      "status": 1,
      "seq": 1,
      "text": [
        {
          "content": "量",
          "index": 0,
          "role": "assistant"
        }
      ]
    }
  }
}

// 最后一个数据块
{
  "header": {
    "code": 0,
    "message": "Success",
    "sid": "cht000704fa@dx16ade44e4d87a1c802",
    "status": 2
  },
  "payload": {
    "choices": {
      "status": 2,
      "seq": 5,
      "text": [
        {
          "content": "算",

        "prompt_tokens": 10,

      }
    }

```

**流式状态码**：

| status值 | 含义 |
|----------|------|
| 0 | 第一个结果 |
| 1 | 中间结果 |
| 2 | 最后一个结果 |

### 4.2 HTTP 协议流式响应

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

data: {"id":"cht000b920a@dx194e0205ccbb8f3700","object":"chat.completion.chunk","created":1234567890,"model":"xdeepseekv3","choices":[{"index":0,"delta":{"role":"assistant","content":""},"finish_reason":null}]}

data: {"id":"cht000b920a@dx194e0205ccbb8f3700","object":"chat.completion.chunk","created":1234567890,"model":"xdeepseekv3","choices":[{"index":0,"delta":{"content":"量"},"finish_reason":null}]}

data: {"id":"cht000b920a@dx194e0205ccbb8f3700","object":"chat.completion.chunk","created":1234567890,"model":"xdeepseekv3","choices":[{"index":0,"delta":{"content":"子"},"finish_reason":null}]}

data: {"id":"cht000b920a@dx194e0205ccbb8f3700","object":"chat.completion.chunk","created":1234567890,"model":"xdeepseekv3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":{"completion_tokens":100,"prompt_tokens":10,"total_tokens":110}}

data: [DONE]
```

**字段说明**：
- `delta.role`: 仅在第一个块中出现，标识角色为 assistant
- `delta.content`: 增量文本内容，需要拼接
- `finish_reason`: 结束原因
  - `stop`: 正常结束
  - `length`: 达到 token 限制
  - `tool_calls`: 需要调用工具
  - `null`: 未结束
- `data: [DONE]`: 流式传输结束标记

### 5.1 WebSocket 协议工具调用


## 6. 响应参数说明

### 6.1 WebSocket 协议响应参数

**平台参数**：

| 字段名 | 类型 | 含义 | 备注 |
|--------|------|------|------|
| header.code | int | 服务错误码 | 0表示正常，非0表示出错 |
| header.sid | string | 会话的sid | - |
| header.status | int | 会话的状态 | 0:第一个结果, 1:中间结果, 2:最后一个结果 |
| header.message | string | 返回消息描述 | 错误码的描述信息 |

**文本响应参数**：

| 字段 | 含义 | 数据类型 | 说明 |
|------|------|----------|------|
| status | 数据状态 | int | 0:开始, 1:中间, 2:结束 |

**Token消耗参数**：

| 字段 | 含义 | 说明 |
|------|------|------|
| completion_tokens | 回答tokens大小 | - |

| prompt_tokens | 问题总tokens大小 | - |
| total_tokens | 问题和回答的tokens大小 | - |

### 6.2 HTTP 协议响应参数

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | string | 本次对话调用的唯一ID |

## 10. 连接管理（WebSocket协议）

### 10.1 建立连接

- 必须符合 websocket 协议规范（rfc6455）
- 需要按照要求进行签名请求
- 60秒内无交互数据，服务侧会主动断开

### 10.2 关闭连接

- 正常交互结束后，客户端发送Close类型消息关闭连接
- 建议用户使用完毕后主动关闭连接
- 如需终止生成，可直接发送websocket的close消息关闭连接
