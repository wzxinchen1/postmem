# 阿里云百炼 API 协议

> 更新时间：2026年5月

## 概述

阿里云百炼（Model Studio）是阿里云推出的一站式大模型服务平台，提供通义千问（Qwen）系列模型及第三方模型的API调用服务。平台提供四种API接口类型：

| 接口类型 | 特点说明 | 适用场景 |
|---------|---------|---------|
| **OpenAI兼容-Chat** | 社区生态成熟，迁移成本最低 | 现有OpenAI应用迁移、第三方工具集成 |
| **OpenAI兼容-Responses** | 内置联网搜索、代码解释器等工具 | 智能体应用、需要内置工具的场景 |
| **Anthropic兼容-Messages** | 兼容Anthropic Messages API | Claude应用迁移、需要思考链特性 |
| **DashScope** | 阿里云原生接口，功能最完整 | 需要完整功能和参数的场景 |

## 一、OpenAI 兼容 - Chat API

### 1.1 服务地址

| 地域 | SDK base_url | HTTP 请求地址 |
|------|-------------|---------------|
| 华北2（北京） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `POST https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 新加坡 | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` | `POST https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 美国（弗吉尼亚） | `https://dashscope-us.aliyuncs.com/compatible-mode/v1` | `POST https://dashscope-us.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 德国（法兰克福） | `https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/compatible-mode/v1` | `POST https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/compatible-mode/v1/chat/completions` |

### 1.2 基础请求格式

```http
POST /compatible-mode/v1/chat/completions HTTP/1.1
Host: dashscope.aliyuncs.com
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "model": "qwen-plus",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "解释量子计算的基本原理"}
  ],
  "stream": true
}
```

### 1.3 请求参数说明

#### 必选参数

| 参数 | 类型 | 说明 |
|------|------|------|
| **model** | string | 模型名称，支持 Qwen、DeepSeek、Kimi、GLM、MiniMax 等系列 |
| **messages** | array | 传递给大模型的上下文，按对话顺序排列 |

#### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| **stream** | boolean | false | 是否流式输出 |
| **stream_options** | object | - | 流式配置，`{"include_usage": true}` 可在最后返回 Token 消耗 |
| **temperature** | float | 模型相关 | 采样温度，控制生成多样性，范围 [0, 2) |
| **top_p** | float | 模型相关 | 核采样概率阈值，范围 (0, 1.0] |
| **max_tokens** | integer | 模型最大值 | 限制输出最大 Token 数 |
| **stop** | string/array | - | 停止词，触发后立即终止生成 |
| **n** | integer | 1 | 生成响应数量（1-4），仅部分模型支持 |
| **response_format** | object | `{"type": "text"}` | 输出格式，可选 `text` 或 `json_object` |
| **seed** | integer | 模型相关 | 随机数种子，用于结果复现 |
| **presence_penalty** | float | 0.0 | 控制内容重复度，范围 [-2.0, 2.0] |
| **frequency_penalty** | float | 0.0 | 控制词频惩罚，范围 [-2.0, 2.0] |
| **logprobs** | boolean | false | 是否返回 Token 对数概率 |
| **top_logprobs** | integer | 0 | 返回最可能的候选 Token 个数，范围 [0, 5] |

#### 非标准参数（通过 extra_body 传入）

| 参数 | 类型 | 说明 |
|------|------|------|
| **top_k** | integer | 候选 Token 数量 |
| **repetition_penalty** | float | 重复惩罚 |
| **enable_search** | boolean | 开启联网搜索 |
| **enable_thinking** | boolean | 开启思考模式 |
| **thinking_budget** | integer | 思考过程最大 Token 数 |

### 1.4 消息类型

#### System Message（可选）

```json
{
  "role": "system",
  "content": "You are a helpful assistant."
}
```

> **注意**: QwQ 模型不建议设置 System Message，QVQ 模型设置 System Message 不会生效。

#### User Message（必选）

**纯文本输入**:

```json
{
  "role": "user",
  "content": "你是谁？"
}
```

**多模态输入（图像/视频/音频）**:

```json
{
  "role": "user",
  "content": [
    {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}},
    {"type": "text", "text": "这是什么？"}
  ]
}
```

| type 类型 | 说明 |
|-----------|------|
| `text` | 输入文本 |
| `image_url` | 输入图片（URL 或 Base64） |
| `input_audio` | 输入音频 |
| `video` | 输入图片列表形式的视频 |
| `video_url` | 输入视频文件 |

#### Assistant Message（可选）

```json
{
  "role": "assistant",
  "content": "我是千问...",
  "tool_calls": [...]  // Function Calling 时包含
}
```

#### Tool Message（可选）

```json
{
  "role": "tool",
  "content": "工具返回结果",
  "tool_call_id": "call_xxx"
}
```

### 1.5 工具调用（Function Calling）

#### 请求示例

```http
POST /compatible-mode/v1/chat/completions HTTP/1.1
Host: dashscope.aliyuncs.com
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "model": "qwen-plus",
  "messages": [
    {"role": "user", "content": "北京今天天气怎么样？"}
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_current_weather",
        "description": "查询指定城市的天气",
        "parameters": {
          "type": "object",
          "properties": {
            "location": {
              "type": "string",
              "description": "城市或县区"
            }
          },
          "required": ["location"]
        }
      }
    }
  ],
  "tool_choice": "auto"
}
```

#### tool_choice 选项

| 值 | 说明 |
|----|------|
| `auto` | 大模型自主选择工具策略 |
| `none` | 禁用工具调用 |
| `{"type": "function", "function": {"name": "xxx"}}` | 强制调用指定工具 |

#### 工具调用响应

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1735120033,
  "model": "qwen-plus",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_xxx",
            "type": "function",
            "function": {
              "name": "get_current_weather",
              "arguments": "{\"location\": \"北京市\"}"
            }
          }
        ]
      },
      "finish_reason": "tool_calls"
    }
  ]
}
```

## 二、深度思考模式

### 2.1 概述

深度思考模型在生成回复前会先进行推理，以提升模型在逻辑推理与数值计算等复杂任务中的准确性。

### 2.2 两种思考模式

| 模式 | 说明 | 参数控制 |
|------|------|----------|
| **混合思考模式** | 可通过参数控制是否开启思考 | `enable_thinking` 参数 |
| **仅思考模式** | 始终在回复前进行思考，无法关闭 | 无需设置参数 |

### 2.3 开启思考模式

```http
POST /compatible-mode/v1/chat/completions HTTP/1.1
Host: dashscope.aliyuncs.com
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "model": "qwen-plus",
  "messages": [
    {"role": "user", "content": "证明：根号2是无理数"}
  ],
  "stream": true,
  "stream_options": {"include_usage": true},
  "enable_thinking": true,
  "thinking_budget": 10000
}
```

### 2.4 思考参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `enable_thinking` | boolean | 控制是否开启思考模式（`true`开启，`false`关闭） |
| `thinking_budget` | integer | 限制推理过程的最大 Token 数，超过限制时模型立即生成回复 |
| `preserve_thinking` | boolean | 多轮对话中是否传递历史思考过程 |

### 2.5 参数传入方式

| SDK/方式 | 传入方法 |
|----------|----------|
| **OpenAI Python SDK** | 通过 `extra_body` 传入（非标准参数） |
| **OpenAI Node.js SDK** | 作为顶层参数直接传入 |
| **DashScope SDK** | 作为顶层参数直接传入 |
| **HTTP 请求** | 放入 `parameters` 对象中 |

### 2.6 提示词控制（部分模型支持）

- **关闭思考**: 在提示词中加上 `/no_think`
- **开启思考**: 在提示词中加上 `/think`
- 模型会遵循最新的 `/think` 或 `/no_think` 指令

### 2.7 多轮对话传递思考过程

```json
{
  "model": "qwen3.6-plus",
  "messages": [
    {"role": "user", "content": "问题1"},
    {
      "role": "assistant",
      "content": "回复内容",
      "reasoning_content": "思考过程内容"
    },
    {"role": "user", "content": "问题2"}
  ],
  "enable_thinking": true,
  "preserve_thinking": true
}
```

### 2.8 流式响应示例（含思考链）

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

// 思考阶段
data: {"choices":[{"delta":{"content":null,"role":"assistant","reasoning_content":"让我用反证法来证明..."}}]}

data: {"choices":[{"delta":{"reasoning_content":"\n\n假设根号2是有理数，即 √2 = p/q，其中 p、q 互质"}}]}

data: {"choices":[{"delta":{"reasoning_content":"\n\n两边平方得：2 = p²/q²，因此 p² = 2q²"}}]}

// 回复阶段（思考结束后）
data: {"choices":[{"delta":{"content":"**证明：根号2是无理数**","reasoning_content":null}}]}

data: {"choices":[{"delta":{"content":"\n\n我们使用反证法..."}}]}

// 结束阶段
data: {"choices":[{"finish_reason":"stop","delta":{"content":"","reasoning_content":null}}]}

// Token 消耗
data: {"usage":{"prompt_tokens":10,"completion_tokens":360,"total_tokens":370,"completion_tokens_details":{"reasoning_tokens":172}}}
```

## 三、OpenAI 兼容 - Responses API

### 3.1 概述

Responses API 是 Chat Completions API 的演进版本，能够以更简洁的方式提供智能体原生功能。

### 3.2 相较于 Chat Completions API 的优势

- **内置工具**：联网搜索、网页抓取、代码解释器、文搜图、图搜图等
- **更灵活的输入**：支持直接传入字符串，也兼容 Chat 格式消息数组
- **简化上下文管理**：通过 `previous_response_id` 自动关联上下文

### 3.3 服务地址

| 地域 | HTTP 请求地址 |
|------|---------------|
| 华北2（北京） | `POST https://dashscope.aliyuncs.com/compatible-mode/v1/responses` |
| 新加坡 | `POST https://dashscope-intl.aliyuncs.com/compatible-mode/v1/responses` |
| 美国（弗吉尼亚） | `POST https://dashscope-us.aliyuncs.com/compatible-mode/v1/responses` |
| 德国（法兰克福） | `POST https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/compatible-mode/v1/responses` |

### 3.4 基础请求格式

```http
POST /compatible-mode/v1/responses HTTP/1.1
Host: dashscope.aliyuncs.com
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "model": "qwen3.6-plus",
  "input": "解释量子计算的基本原理",
  "stream": true,
  "reasoning": {
    "effort": "medium"
  },
  "tools": [
    {"type": "web_search"},
    {"type": "code_interpreter"}
  ]
}
```

### 3.5 核心请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 模型名称（必填） |
| `input` | string/array | 输入内容，支持字符串或消息数组格式 |
| `previous_response_id` | string | 上一轮响应的 ID，用于多轮对话（有效期 7 天） |
| `stream` | boolean | 是否启用流式输出 |
| `tools` | array | 内置工具配置 |
| `reasoning` | object | 推理控制参数 |

### 3.6 深度思考参数

```json
{
  "reasoning": {
    "effort": "medium"
  }
}
```

| effort 值 | 说明 |
|-----------|------|
| `none` | 关闭思考，直接回答 |
| `minimal` | 最小化思考，最快速响应 |
| `low` | 轻度思考，侧重快速响应 |
| `medium`（默认） | 中度思考，平衡速度与深度 |
| `high` | 深度思考，处理复杂专业问题 |

### 3.7 内置工具类型

```json
{
  "tools": [
    {"type": "web_search"},       // 联网搜索
    {"type": "code_interpreter"}, // 代码解释器
    {"type": "web_extractor"}     // 网页抓取
  ]
}
```

### 3.8 响应结构

```json
{
  "id": "resp_xxx",
  "object": "response",
  "created_at": 1771225825,
  "model": "qwen3.6-plus",
  "status": "completed",
  "output": [
    {
      "id": "msg_xxx",
      "type": "reasoning",
      "summary": [{"type": "summary_text", "text": "思考过程..."}]
    },
    {
      "id": "msg_xxx",
      "type": "message",
      "role": "assistant",
      "status": "completed",
      "content": [
        {
          "type": "output_text",
          "text": "回复内容...",
          "annotations": []
        }
      ]
    }
  ],
  "usage": {
    "input_tokens": 49,
    "output_tokens": 1384,
    "total_tokens": 1433,
    "output_tokens_details": {
      "reasoning_tokens": 1110
    }
  }

```

### 3.9 输出类型

| type | 说明 |
|------|------|
| `reasoning` | 思考过程输出 |
| `message` | 最终消息内容 |
| `web_search_call` | 网络搜索调用 |
| `web_extractor_call` | 网页抓取调用 |

### 3.10 Session 缓存

**开启方式**: 在请求 Header 中添加 `x-dashscope-session-cache: enable`

**支持模型**: qwen3-max、qwen3.6-plus、qwen3.5-plus、qwen3.6-flash、qwen3.5-flash、qwen-plus、qwen-flash、qwen3-coder-plus、qwen3-coder-flash

**缓存规则**:
- 最小缓存长度：1024 Token
- 缓存有效期：5 分钟

### 3.11 流式输出事件类型

| 事件类型 | 说明 |
|----------|------|
| `response.created` | 响应创建 |
| `response.in_progress` | 响应进行中 |
| `response.output_text.delta` | 增量文本输出 |
| `response.output_text.done` | 文本输出完成 |
| `response.completed` | 响应完成 |

### 4.1 服务地址

| 地域 | SDK base_url | HTTP 请求地址 |
|------|-------------|---------------|
| 华北2（北京） | `https://dashscope.aliyuncs.com/apps/anthropic` | `POST https://dashscope.aliyuncs.com/apps/anthropic/v1/messages` |
| 新加坡 | `https://dashscope-intl.aliyuncs.com/apps/anthropic` | `POST https://dashscope-intl.aliyuncs.com/apps/anthropic/v1/messages` |
| 美国（弗吉尼亚） | `https://dashscope-us.aliyuncs.com/apps/anthropic` | `POST https://dashscope-us.aliyuncs.com/apps/anthropic/v1/messages` |
| 德国（法兰克福） | `https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/apps/anthropic` | `POST https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/apps/anthropic/v1/messages` |

### 4.2 认证方式

- 通过 `x-api-key` 请求头传入百炼 API Key
- 或通过 `Authorization: Bearer` 请求头传入（二选一）

### 4.3 从 Anthropic 迁移配置

只需修改以下三项配置即可迁移：

1. **api_key**: 替换为百炼 API Key
2. **base_url**: 替换为百炼的兼容端点地址
3. **model**: 替换为百炼支持的模型名称（如 `qwen3.6-plus`）

### 4.4 基础请求格式

```http
POST /apps/anthropic/v1/messages HTTP/1.1
Host: dashscope.aliyuncs.com
x-api-key: YOUR_API_KEY
anthropic-version: 2023-06-01
Content-Type: application/json

{
  "model": "qwen3.6-plus",
  "max_tokens": 4096,
  "messages": [
    {"role": "user", "content": "解释相对论的基本原理"}
  ],
  "thinking": {
    "type": "enabled",
    "budget_tokens": 1024
  }
}
```

### 4.5 请求参数说明

#### 必选参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | string | 模型名称 |
| `max_tokens` | integer | 生成 Token 的最大数量 |
| `messages` | array | 消息数组，按 user/assistant 交替排列 |

#### 可选参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `system` | string 或 array | 系统提示词，设定模型角色或行为 |
| `stream` | boolean | 是否启用流式输出，默认 false |
| `temperature` | number | 控制生成多样性，范围 [0, 2) |
| `top_p` | number | 核采样概率阈值 |
| `top_k` | integer | 采样候选集大小 |
| `stop_sequences` | array | 停止生成的文本序列 |
| `thinking` | object | 深度思考配置 |
| `tools` | array | 工具定义数组 |
| `tool_choice` | object | 工具选择策略 |
| `reasoning_effort` | string | 推理强度，可选值：high、max |

### 4.6 消息内容类型

#### content 数组支持的类型

| 类型 | type 值 | 说明 |
|------|---------|------|
| 文本 | `text` | 文本内容 |
| 图片 | `image` | 支持 URL 或 Base64 |
| 视频 | `video` | 支持 URL 或 Base64 |
| 工具调用 | `tool_use` | assistant 角色返回的工具调用指令 |
| 工具结果 | `tool_result` | user 角色回传的工具执行结果 |

### 4.7 深度思考配置

```json
{
  "thinking": {
    "type": "enabled",
    "budget_tokens": 1024
  }
}
```

### 4.8 非流式响应示例

```json
{
  "id": "msg_xxx",
  "type": "message",
  "role": "assistant",
  "model": "qwen3.6-plus",
  "content": [
    {"type": "thinking", "thinking": "...", "signature": ""},
    {"type": "text", "text": "..."}
  ],
  "stop_reason": "end_turn",
  "stop_sequence": null,
  "usage": {
    "input_tokens": 22,
    "output_tokens": 223,
    "cache_creation_input_tokens": 0,
    "cache_read_input_tokens": 0
  }
}
```

### 4.9 流式响应事件类型

| 事件类型 | 说明 |
|---------|------|
| `message_start` | 消息开始 |
| `content_block_start` | 内容块开始 |
| `content_block_delta` | 内容块增量更新 |
| `content_block_stop` | 内容块结束 |
| `message_delta` | 消息级更新（含完整 Token 用量） |
| `message_stop` | 消息结束 |
| `ping` | 保持连接活跃 |

### 4.10 显式缓存

通过 `cache_control` 标记缓存断点，最小缓存长度为 1024 Token：

```json
{
  "type": "text",
  "text": "长文本内容...",
  "cache_control": {"type": "ephemeral"}
}
```

### 4.11 注意事项

1. **temperature 范围差异**: 百炼的范围是 [0, 2)，与 Anthropic 官方的 [0.0, 1.0] 不同
2. **stop_sequences 行为**: 命中后 `stop_reason` 仍为 `end_turn`，不会回填命中的序列
3. **system 参数**: 通过顶层参数传入，messages 数组中不接受 system 角色
4. **德国区域**: 需将 `{WorkspaceId}` 替换为真实的 Workspace ID

## 八、最佳实践

### 8.1 API Key 管理

- 通过环境变量 `DASHSCOPE_API_KEY` 配置
- 避免在代码中硬编码 API Key
- 定期轮换 API Key

### 8.2 流式调用建议

- 长输出场景建议使用流式调用
- 非流式调用超过 300 秒未完成会中断请求
- 设置 `stream_options.include_usage: true` 获取 Token 消耗统计

### 8.3 JSON 输出

设置 `response_format: {"type": "json_object"}` 时需在提示词中明确指示输出 JSON 格式。

### 8.4 深度思考使用场景

**推荐使用思考链的场景**:
- 复杂数学推理
- 逻辑分析问题
- 多步骤任务规划
- 代码调试与优化
- 科学研究问题

**不推荐使用思考链的场景**:
- 简单问答
- 创意写作
- 翻译任务
- 情感对话

### 8.5 计费说明

- **思考内容**: 按照输出 Token 计费
- **混合思考模型**: 思考与非思考模式下的价格可能不同
- 若模型在思考模式下未输出思考过程，按非思考模式价格计费
- `preserve_thinking` 开启后，历史思考过程会计入输入 Token 数量和计费
