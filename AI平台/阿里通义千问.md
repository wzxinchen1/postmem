# 阿里通义千问 API 协议

## 1. 基础请求格式

### 1.1 API 请求地址

按地域划分的 HTTP 端点：

| 地域 | 纯文本模型 | 多模态模型 |
|------|-----------|-----------|
| **华北2（北京）** | `https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation` | `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` |
| **新加坡** | `https://dashscope-intl.aliyuncs.com/api/v1/services/aigc/text-generation/generation` | `https://dashscope-intl.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` |
| **美国（弗吉尼亚）** | `https://dashscope-us.aliyuncs.com/api/v1/services/aigc/text-generation/generation` | `https://dashscope-us.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` |
| **德国（法兰克福）** | `https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/api/v1/services/aigc/text-generation/generation` | `https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` |

### 1.2 基础请求示例

```http
POST /api/v1/services/aigc/text-generation/generation HTTP/1.1
Host: dashscope.aliyuncs.com
Authorization: Bearer sk-xxx
Content-Type: application/json

{
  "model": "qwen-max",
  "input": {
    "messages": [
      {"role": "user", "content": "解释深度学习的原理"}
    ]
  },
  "parameters": {
    "result_format": "message"
  }
}
```

## 2. 输入参数详解

### 2.1 必选参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| **model** | string | 模型名称。支持：Qwen大语言模型、Qwen-VL、Qwen-Coder、Qwen-Audio、数学模型、DeepSeek、Kimi、GLM、MiniMax等 |
| **messages** | array | 传递给大模型的上下文，按对话顺序排列 |

### 2.2 消息对象类型

#### System Message（可选）

```json
{
  "role": "system",
  "content": "You are a helpful assistant."
}
```

> **注意**：QwQ模型不建议设置System Message，QVQ模型设置System Message不会生效

#### User Message（必选）

```json
{
  "role": "user",
  "content": "你是谁？"  // 或包含多模态数据的数组
}
```

**content 支持的多模态类型**：

| 类型 | 参数 | 说明 |
|------|------|------|
| 文本 | `text` | 输入的文本 |
| 图像 | `image` | 公网URL、Base64编码或本地文件路径 |
| 视频 | `video` | 图像列表或视频文件URL |
| 音频 | `audio` | 音频文件URL |

**视频参数配置**：
- `fps`: 每秒抽帧数，范围[0.1, 10]，默认2.0
- `max_frames`: 最大抽取帧数
- `min_pixels`: 最小像素阈值
- `max_pixels`: 最大像素阈值
- `total_pixels`: 所有帧总像素限制

#### Assistant Message（可选）

```json
{
  "role": "assistant",
  "content": "回复内容",
  "tool_calls": [...]  // Function Calling时使用
}
```

#### Tool Message（可选）

```json
{
  "role": "tool",
  "content": "工具输出内容",
  "tool_call_id": "工具响应ID"
}
```

### 2.3 可选参数

#### 采样控制参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| **temperature** | float | 见下表 | 采样温度，控制生成多样性，范围[0, 2) |
| **top_p** | float | 见下表 | 核采样概率阈值，范围(0, 1.0] |
| **top_k** | integer | 见下表 | 采样候选集大小 |
| **repetition_penalty** | float | 1.0~1.2 | 重复惩罚，大于0 |
| **presence_penalty** | float | -2.0~2.0 | 存在惩罚，正值降低重复度 |

**各模型默认值示例**：
- Qwen3.6/3.5/3（非思考模式）: temperature=0.7, top_p=0.8
- QVQ系列: temperature=0.5, top_p=0.5, top_k=10
- QwQ系列: temperature=0.6, top_p=0.95, top_k=40

#### 输出控制参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| **max_tokens** | integer | 模型最大输出长度 | 限制输出最大Token数 |
| **stream** | boolean | false | 是否流式输出 |
| **incremental_output** | boolean | false | 流式模式下是否增量输出 |
| **result_format** | string | text/message | 返回数据格式 |
| **response_format** | object | {"type": "text"} | 输出格式，支持json_object |
| **n** | integer | 1 | 生成响应个数，范围1-4 |
| **stop** | string/array | - | 停止词 |

#### 思考模式参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| **enable_thinking** | boolean | 是否开启思考模式（Qwen3.6/3.5/3、DeepSeek-V4等） |
| **preserve_thinking** | boolean | 是否保留历史思考内容 |
| **thinking_budget** | integer | 思考过程最大长度 |
| **reasoning_effort** | string | DeepSeek-V4推理力度：high/max |

#### 工具调用参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| **tools** | array | 工具对象数组 |
| **tool_choice** | string/object | 工具选择策略：auto/none/指定工具 |
| **parallel_tool_calls** | boolean | 是否开启并行工具调用 |

#### 联网搜索参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| **enable_search** | boolean | 是否启用联网搜索 |
| **search_options** | object | 搜索策略配置 |

**search_options 子参数**：

```json
{
  "enable_source": false,        // 是否展示搜索来源
  "enable_citation": false,      // 是否开启角标标注
  "citation_format": "[<number>]", // 角标样式
  "forced_search": false,        // 是否强制搜索
  "search_strategy": "turbo",    // turbo/max/agent/agent_max
  "enable_search_extension": false // 特定领域增强
}
```

#### 其他参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| **seed** | integer | 随机数种子，范围[0, 2³¹-1] |
| **logprobs** | boolean | 是否返回Token对数概率 |
| **top_logprobs** | integer | 返回最大概率候选Token个数，范围[0,5] |
| **enable_code_interpreter** | boolean | 是否开启代码解释器 |
| **skill** | array | 技能参数（如PPT生成） |

## 3. 开启思考链（Thinking Mode）

### 3.1 思考模式请求

```http
POST /api/v1/services/aigc/text-generation/generation HTTP/1.1
Host: dashscope.aliyuncs.com
Authorization: Bearer sk-xxx
Content-Type: application/json
X-DashScope-SSE: enable

{
  "model": "qwen3-max",
  "input": {
    "messages": [
      {"role": "user", "content": "请详细分析：为什么需要深度学习？"}
    ]
  },
  "parameters": {
    "result_format": "message",
    "enable_thinking": true,
    "thinking_budget": 10000,
    "incremental_output": true,
    "stream": true
  }
}
```

### 3.2 思考模式响应

```json
{
  "output": {
    "choices": [
      {
        "finish_reason": "stop",
        "message": {
          "role": "assistant",
          "content": "深度学习之所以重要，是因为...",
          "reasoning_content": "让我思考一下深度学习的必要性...\n\n首先，传统机器学习在处理复杂问题时..."
        }
      }
    ]
  },
  "usage": {
    "input_tokens": 20,
    "output_tokens": 500,
    "output_tokens_details": {
      "text_tokens": 400,
      "reasoning_tokens": 100
    }
  }
}
```

**关键说明**：
- 支持思考模式的模型：Qwen3.6/3.5/3、DeepSeek-V4 等
- 思考内容通过 `reasoning_content` 字段返回
- `thinking_budget` 控制思考过程最大长度
- Qwen3商业版（思考模式）、Qwen3开源版、QwQ、QVQ 只支持流式输出

```http
    ]
  },

    "result_format": "message",
    "incremental_output": true,
    "stream": true
  }
}
```

### 4.2 流式响应（SSE 格式）

```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

data: {"output":{"choices":[{"message":{"role":"assistant","content":"我"},"finish_reason":null}]},"request_id":"xxx"}

data: {"output":{"choices":[{"message":{"role":"assistant","content":"是"},"finish_reason":null}]},"request_id":"xxx"}

data: {"output":{"choices":[{"message":{"role":"assistant","content":"阿里云"},"finish_reason":null}]},"request_id":"xxx"}

data: {"output":{"choices":[{"message":{"role":"assistant","content":"开发的"},"finish_reason":null}]},"request_id":"xxx"}

// ... 更多内容

data: {"output":{"choices":[{"message":{"role":"assistant","content":"语言模型"},"finish_reason":"stop"}]},"usage":{"total_tokens":100,"input_tokens":10,"output_tokens":90},"request_id":"xxx"}
```

**字段说明**：
- `message.role`: 标识角色为 assistant
- `message.content`: 增量文本内容，需要拼接
- `finish_reason`: 结束原因
  - `stop`: 正常结束
  - `length`: 达到 token 限制
  - `tool_calls`: 需要调用工具
  - `null`: 未结束
- `usage`: Token 使用统计

## 10. SDK 调用示例

### 10.1 Python SDK - 基础调用

```python
import os
import dashscope

messages = [
    {'role': 'system', 'content': 'You are a helpful assistant.'},
    {'role': 'user', 'content': '你是谁？'}
]
response = dashscope.Generation.call(
    api_key=os.getenv('DASHSCOPE_API_KEY'),
    model="qwen-plus",
    messages=messages,
    result_format='message'
)
print(response)
```

### 10.2 Python SDK - 流式输出

```python
import os
import dashscope

messages = [
    {'role':'system','content':'you are a helpful assistant'},
    {'role': 'user','content': '你是谁？'}
]
responses = dashscope.Generation.call(
    api_key=os.getenv('DASHSCOPE_API_KEY'),
    model="qwen-plus",
    messages=messages,
    result_format='message',
    stream=True,
    incremental_output=True
)
for response in responses:
    print(response)
```

## 13. 错误处理

如果模型调用失败并返回报错信息，请参见错误信息进行解决。

**常见错误**：
- API Key 配置错误
- 地域不匹配（新加坡和北京地域的API Key不通用）
- 参数格式错误
- 模型不存在

**错误码文档**：https://help.aliyun.com/zh/model-studio/developer-reference/error-code

## 14. 重要注意事项

1. **API Key配置**：需要设置环境变量 `DASHSCOPE_API_KEY` 或在代码中直接传入
2. **不同地域API Key不同**：新加坡和北京地域的API Key不通用
3. **流式输出限制**：Qwen3商业版（思考模式）、Qwen3开源版、QwQ、QVQ只支持流式输出
4. **思考模式**：开启后思考内容通过 `reasoning_content` 字段返回
5. **联网搜索**：启用可能增加Token消耗
6. **System Message限制**：QwQ模型不建议设置，QVQ模型设置不会生效

## 15. OpenAI 兼容接口

阿里云百炼提供 OpenAI 兼容接口，支持使用 OpenAI SDK 直接调用：

- **基础 URL**：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- **接口路径**：`/chat/completions`
- **支持模型**：`qwen-turbo`、`qwen-plus`、`qwen-max` 等
